# Curifo Custom IaC システム仕様書

## 1. システム概要
本システムは、平行透視（アイソメトリック）によるグリッド上の土地に、サーバーラック風のAWSリソース（EC2、Lambda、RDS、S3など）を配置し、シミュレーションゲームのように直感的にクラウドインフラを設計・管理・即時デプロイできる次世代IaC（Infrastructure as Code）システムである。

* **投影方式:** 平行透視（Orthographic Projection / 消失点なしの等角投影）。

## 3. 全体アーキテクチャ（サーバーレス・コントロールプレーン方式）

クライアント側での秘密鍵管理や重いTerraform実行を排除し、**「Reactフロントエンド（JSON生成） ➔ 司令塔Lambda ➔ AWS SDK直接実行」** の超高速・高セキュリティなパイプラインを採用する。

```
┌─────────────────────────────────────────────────────────────┐
│  フロントエンド (本システム: React / Vite)                  │
│  ・アイソメトリックグリッド土地でのドラッグ＆ドロップ配置   │
│  ・リソーススペック・設定の直感的編集 (Inspector)           │
│  ・現在のインフラ構成を宣言的JSONとして生成                 │
└──────────────────────────────┬──────────────────────────────┘
                               │ HTTP POST (構成JSON)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│  AWS API Gateway / Lambda Function URL                      │
└──────────────────────────────┬──────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────┐
│  司令塔 Lambda (AWS SDK実行エンジン)                        │
│  ・IAMロールによる安全な実行（クライアントの鍵不要）        │
│  ・受け取ったJSONを解析し、AWS SDK (v3) を直接コール        │
│  ・EC2 / RDS / Lambda / S3 の即時デプロイ・破棄             │
└──────────────────────────────┬──────────────────────────────┘
                               ▼
┌─────────────────────────────────────────────────────────────┐
│  実AWSクラウドリソース (EC2, RDS, Lambda, S3...)            │
└─────────────────────────────────────────────────────────────┘
```

### アーキテクチャのメリット
1. **完全ゼロ・クレデンシャル（最高峰のセキュリティ）:**
   ブラウザやローカルPCにAWSアクセスキーを一切保持しない。権限はAWS上のLambdaのIAMロールに集約。
2. **超高速・即時デプロイ:**
   Terraformの事前プラン作成やステートロックを挟まず、配置した瞬間にAWS SDKでリソースを立ち上げる。
3. **身軽なWebホスティング:**
   本システム自体は静的サイトとして完結するため、GitHub PagesやS3からでも動作可能。

## 5. UI/UX 仕様

| コンポーネント | 役割・機能 |
| :--- | :--- |
| **Header** | プロジェクト名、現在の稼働リソース数バッジ、ライン接続数バッジ、「構成JSON (入出力)」「即時デプロイ」ボタン |
| **ResourcePalette (左)** | S3 / CloudFront / API Gateway / Lambda / DynamoDB / Cognito の選択カード。クリックまたはグリッドへの直接ドラッグ配置に対応 |
| **IsometricGrid (中央)** | 6×6（36区画）の平行透視グリッド。タイルの浮き上がりホバー、禁止アイコンのない滑らかなDnD移動・配置。リソース間を流れる光の接続ライン（SVG レイヤー）。**カメラ視点操作機能（ズームイン/アウト、45°ステップ回転、マウスホイールズーム、右ドラッグ自由回転、2D見取り図/3D立体ビュー切替、初期位置リセット）**を完備 |
| **ServerRack** | タイル相似形の底面から鉛直に立ち上がる純粋CSS 3D直方体。リソース種別に応じた高さ押し出し、天面バッジ、排気スリット、薄緑点滅LED |
| **Inspector (右)** | 選択中リソースのスペック、月額見積もり、IaCパラメーター確認、**接続ライン（送出先/呼出元リソース）の確認**、および撤去ボタン |
| **JsonModal** | 構成JSONのエクスポート（ファイル保存・クリップボードコピー）および**JSONインポート（貼り付け・ファイル選択・「東京Curifo本番構成」クイックプリセット反映）** |
